# The Performance Testing Judgment Pack — landing page

Static GitHub Pages site for the pre-order proof test of David Edelstein's performance-testing heuristics pack.

- `index.html` — the landing page (single file, no build step, no dependencies)
- `sample-chapter.md` — the free sample chapter (Chapter 2: After the Test — Reading k6 Output Without Fooling Yourself)

Checkout is handled by Gumroad (pre-order; cards are charged on the release date). The buy buttons in `index.html` connect to the Gumroad listing when it goes live.

Proof test: the full pack is built only if pre-orders reach the set bar during the promotion window. The page states this plainly — that honesty is part of the test design.
